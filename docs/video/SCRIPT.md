**3분 이내 · 나레이션 없음 · 자막 한/영 두 벌.** 자막 파일은
[subtitles.ko.srt](subtitles.ko.srt) · [subtitles.en.srt](subtitles.en.srt),
타이틀·마무리 카드 문구는 [title-cards.md](title-cards.md) 에 있다.

진행 방법(무엇을 누르면 무엇이 뜨는지)은 [DEMO.md](../DEMO.md) 가 기준이다. 이 문서는
그걸 영상 컷으로 자른 것이다. 자막은 DEMO.md §6 "말하면 안 되는 것" 을 지킨다:

- A1~A6 공격 줄은 **로컬 회로 실행** 결과다. 그렇게 적는다
- 실제 체인 A6 는 **원본(제출) 컨트랙트** 결과다 (2026-09-27 통과). 연습용 결과는 쓰지 않는다
- "금융사는 채권 내용을 모른다" 가 아니라 **"금융사끼리 서로의 장부를 보지 않는다"**
- A5 의 실제 체인 경합은 검증하지 않았다 (지갑 2개 필요). 마무리 카드에 한계로 적는다

## 녹화 순서

컷을 따로 찍고 편집에서 잇는다.

### 1. 로컬 테이크 — 컷 1~4 를 한 번에

- [ ] `pnpm dev` → 상단에 `local-circuit`
- [ ] 콘솔 하단 **데모 초기화**
- [ ] 다른 탭 전부 닫고 `/console` 새로고침 → F11
- [ ] 납품업체 칸 스크롤을 채권 목록이 보이게 맞춘다
- [ ] 녹화 시작 → 컷 1~4 연속. 틀리면 **데모 초기화** 후 처음부터

확인할 숫자 (DEMO.md 기준, 녹화본에서 대조):
금융사 A 예치 1,000,000,000 → **920,000,000** · 금융사 B **1,000,000,000 그대로** ·
A5 나간 자금 **40,000,000** · A1~A6 전부 `통과`

### 2. Preprod 테이크 — 컷 5

- [ ] 서버를 끄고 `pnpm dev:preprod` (원본 `52a72d93…`)
- [ ] `/console` 상단 `preprod` + 블록 높이 5초
- [ ] 위 탐색기 링크 두 개를 차례로 열어 상태 표시를 찍는다
- [ ] **신청 버튼·공격 버튼은 누르지 않는다** (원본 채권은 2건뿐)

### 3. 편집

- [ ] 타이틀 카드 3장 앞에, 마무리 카드 뒤에 ([title-cards.md](title-cards.md))
- [ ] 로딩·대기 구간은 컷한다. **배속을 쓰면 화면에 "×2" 를 적는다** (DEMO.md §6)
- [ ] SRT 두 파일의 시간을 실제 컷에 맞춘다. 한/영은 같은 번호·같은 시간을 쓴다
- [ ] 자막은 화면 하단, 공격 줄을 가리지 않게 컷 4 에서는 위로 올린다
