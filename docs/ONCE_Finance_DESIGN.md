# ONCE Finance: 프론트엔드 디자인 명세

`docs/DESIGN.md` · `SPEC.md` §9와 함께 읽는다.

이 문서는 **화면이 어떻게 보여야 하는지**를 고정한다. 여기서 벗어난 시각적 결정을 하지 않는다. 판단이 필요하면 §7 자가 점검을 먼저 돌린다.

---

## 1. 방향: 여신 단말기

이 제품은 금융사의 여신 심사 화면이다. 소비자 앱이 아니고 랜딩 페이지도 아니다.

참고하는 시각 언어는 **은행 백오피스 단말과 전표**다. 특징은 이렇다.

- 정보 밀도가 높다. 여백으로 고급스러움을 만들지 않는다
- 둥근 모서리가 없다. `border-radius: 0`
- 그림자가 없다. 입체감은 1px 하드 보더로 만든다
- 장식이 없다. 모든 요소가 정보를 나른다
- 숫자가 자릿수로 정렬된다

이 언어를 쓰는 이유는 취향이 아니다. **화면 전체가 조용해야 거부 순간이 폭발하기 때문이다.** 모든 곳이 화려하면 중요한 순간이 묻힌다.

### 1.1 하나의 표현적 순간

과감함은 한 곳에만 쓴다: **도장**.

`nullifier`는 "한 번만 찍히는 도장"이다. 제품의 개념이 곧 화면의 은유다. 대출이 확정되면 도장이 찍히고, 중복이면 도장이 내려오다 멈추고 이미 찍힌 자국이 드러난다.

이 두 순간 말고 화면 어디에도 애니메이션을 넣지 않는다. hover 트랜지션, 페이드인 진입, 카드 부상 효과 전부 금지다.

## 2. 토큰

문서·슬라이드와 색을 공유한다. 세 매체가 같은 언어를 쓰면 완성도가 올라간다.

```css
:root{
  /* 바탕: 사무실 전표 용지 */
  --bg:        #E6E8E3;   /* 앱 배경 */
  --panel:     #F7F8F4;   /* 단말 패널 */
  --panel-2:   #EEF0EA;   /* 패널 내부 구획 */

  /* 선: 입체감은 전부 여기서 */
  --line:      #B6BAB0;   /* 주 경계 1px */
  --line-soft: #D3D6CE;   /* 행 구분선 */
  --line-hard: #1A1D18;   /* 헤더 하단 2px */

  /* 글자 */
  --ink:       #161A14;
  --ink-2:     #4A4F47;
  --ink-3:     #7C8178;   /* 라벨 */

  /* 상태 */
  --seal:      #B0342B;   /* 도장·거부 */
  --seal-bg:   #F1E0DC;
  --settle:    #1F4E79;   /* 확정·전표 청색 */
  --settle-bg: #DEE7EF;
  --wait:      #8A8F84;
}
```

### 2.1 금지된 색

- 보라·인디고 계열 전부 (`violet`, `indigo`, `purple`)
- 그라데이션 배경: 선형이든 방사형이든
- Tailwind 기본 `slate` / `zinc` 회색 팔레트를 그대로 쓰는 것
- 형광 계열 강조색 (acid green, 네온)
- 반투명 유리 효과 (`backdrop-filter`)

### 2.2 다크 모드

만들지 않는다. 데모는 단일 테마로 고정한다. 시간을 여기에 쓰지 않는다.

## 3. 타이포그래피

```css
--font: "IBM Plex Sans KR", system-ui, -apple-system, sans-serif;
```

한 서체만 쓴다. 위계는 굵기와 색으로 만든다.

| 용도 | 크기 | 굵기 | 색 |
|---|---|---|---|
| 패널 제목 | 15px | 600 | `--ink` |
| 본문 | 14px | 400 | `--ink` |
| 라벨 | 12.5px | 400 | `--ink-3` |
| 금액 | 16px | 500 | `--ink` |
| 상태 텍스트 | 13px | 600 | 상태색 |

### 3.1 숫자

금액과 해시는 자릿수 정렬한다.

```css
.num { font-variant-numeric: tabular-nums; letter-spacing: 0 }
```

**모노스페이스 폰트로 바꾸지 않는다.** 작은 데이터 라벨에 mono를 쓰는 건 AI 생성물의 흔한 표식이다. `tabular-nums`면 정렬 문제가 해결된다.

해시는 `0x4f3a…c219` 형태로 줄인다. 앞 6자 + 뒤 4자.

### 3.2 금지

- 대문자 라벨 (`text-transform: uppercase`): 가장 흔한 표식
- 제목에서 한 단어만 색이나 굵기를 다르게 하는 것
- 가운뎃점으로 메타 정보 잇기 (`A · B · C`)
- 버튼·링크 텍스트 끝에 `→` 붙이기
- 제목 위에 작은 설명 라벨 올리기

## 4. 레이아웃

```
┌────────────────────────────────────────────────────────────┐
│  ONCE Finance                          연결됨 · Preprod     │  40px
├──────────────────┬──────────────────┬──────────────────────┤
│  납품업체         │  금융사 A         │  금융사 B            │
│  ──────────────  │  ──────────────  │  ──────────────      │
│                  │                  │                      │
│  보유 채권        │  대출 심사        │  대출 심사            │
│  ┌────────────┐  │                  │                      │
│  │ 채권 #1    │  │   [ 도장 영역 ]   │   [ 도장 영역 ]       │
│  │ 채권 #2    │  │                  │                      │
│  │ 채권 #3    │  │   상태            │   상태                │
│  └────────────┘  │   금액            │   금액                │
│  [A에 신청]      │   tx              │   tx                 │
│  [B에 신청]      │                  │                      │
├──────────────────┴──────────────────┴──────────────────────┤
│  공개 원장                                                  │
│  nullifier        금융사    금액          블록    tx         │
│  0x4f3a…c219      A        80,000,000    1042   0x7b…      │
├────────────────────────────────────────────────────────────┤
│  공격 시나리오  [A1][A2][A3][A4][A5][A6]                    │
└────────────────────────────────────────────────────────────┘
```

- 3열 고정. 반응형 분기는 만들지 않는다. 데모는 데스크톱 한 해상도(1440×900 기준)에서만 돈다
- 패널 사이는 1px `--line`. 간격을 벌리지 않는다. 카드가 떠 있는 게 아니라 단말이 붙어 있는 것이다
- 공개 원장은 화면 하단에 항상 보인다. 접거나 탭으로 숨기지 않는다

### 4.1 공개 원장 패널이 가장 중요하다

발표의 핵심 주장이 "장부는 안 보여줬는데 사기는 막혔다"이다. 이 패널에 **채권 내용 필드를 렌더링하는 코드가 존재해서는 안 된다.** 숨기는 게 아니라 만들지 않는다.

컬럼은 이것만이다: `nullifier`, 금융사, 금액, 블록, tx 해시.

## 5. 컴포넌트 규격

### 5.1 패널

```css
.panel{
  background: var(--panel);
  border-right: 1px solid var(--line);
  border-radius: 0;
  box-shadow: none;
  padding: 0;
}
.panel__head{
  padding: 10px 14px;
  border-bottom: 2px solid var(--line-hard);
  font-size: 15px; font-weight: 600;
  display: flex; justify-content: space-between; align-items: baseline;
}
.panel__body{ padding: 14px }
```

패널 제목 오른쪽에 역할 식별자를 `--ink-3`으로 작게 둔다. 아이콘을 넣지 않는다.

### 5.2 채권 행

```
┌──────────────────────────────────┐
│ 채권 #1                    미사용 │
│ 액면 100,000,000                 │
│ 한도 80,000,000                  │
└──────────────────────────────────┘
```

- 액면금액과 한도만 표시한다. 구매기업명, 지급일, 승인번호는 납품업체 화면에만 보이고 다른 패널에는 **전달조차 하지 않는다**
- 상태는 `미사용` / `사용됨` 텍스트. 알약 모양 배지에 그라데이션을 넣지 않는다
- 선택된 행은 왼쪽 3px `--settle` 보더로 표시한다. 배경색을 바꾸지 않는다

### 5.3 도장

각 금융사 패널의 중앙. 96×96px.

**대기 상태**: 점선 원 `1px dashed var(--line)`, 내부 비어 있음.

**확정**:
```
원형 96px, 3px solid var(--settle), 배경 var(--settle-bg)
텍스트 "지급\n완료", 600, 15px, var(--settle)
transform: rotate(-9deg)
```
등장: `scale(1.35) → scale(1)`, 140ms, `cubic-bezier(.2,.8,.3,1)`. 회전은 처음부터 고정. 도장이 내려와 찍히는 느낌이지 튀어오르는 느낌이 아니다.

**거부**:
```
원형 96px, 3px solid var(--seal), 배경 var(--seal-bg)
텍스트 "이미\n사용", var(--seal)
transform: rotate(-9deg)
```
등장: 위에서 `translateY(-14px)` 내려오다 `translateY(0)`에서 멈추고, 좌우 2px 흔들림 1회(총 180ms). 그 후 도장 아래에 `이 채권은 다른 금융사에서 사용 승인되었습니다` 한 줄, 13px `--seal`.

**거부 시 반드시 금액을 `0`으로 표시한다.** 자금이 나가지 않았다는 게 이 제품의 주장이므로, 화면에 숫자로 남아야 한다.

### 5.4 버튼

```css
.btn{
  border: 1px solid var(--line-hard);
  background: var(--panel-2);
  border-radius: 0;
  padding: 8px 16px;
  font-size: 13.5px; font-weight: 500;
  cursor: pointer;
}
.btn:active{ background: var(--line-soft) }
.btn:disabled{ color: var(--ink-3); border-color: var(--line) }
```

- `:hover` 스타일을 정의하지 않는다. `:active`만 둔다
- 아이콘을 넣지 않는다
- 주요/보조 버튼을 색으로 구분하지 않는다. 배치 순서로 구분한다

### 5.5 원장 테이블

```css
.ledger th{
  font-size: 12px; font-weight: 400; color: var(--ink-3);
  text-align: left; padding: 6px 12px 6px 0;
  border-bottom: 1px solid var(--line);
}
.ledger td{
  font-size: 13.5px; padding: 7px 12px 7px 0;
  border-bottom: 1px solid var(--line-soft);
}
.ledger td.num{ text-align: right; font-variant-numeric: tabular-nums }
```

새 행이 추가될 때 애니메이션을 넣지 않는다. 그냥 나타난다.

## 6. 사용 금지 목록

에이전트가 습관적으로 넣는 것들이다. 하나도 넣지 않는다.

**라이브러리·패턴**
- shadcn/ui 기본 테마 그대로 사용
- lucide-react 아이콘 (아이콘 자체를 쓰지 않는다)
- framer-motion (§5.3의 두 모션은 CSS로 충분하다)
- 3D, 파티클, 캔버스 배경
- 스켈레톤 로더: 데이터가 없으면 `—`를 표시한다

**시각 요소**
- `border-radius` 0 이외의 값
- `box-shadow` 전부
- 그라데이션 전부
- 이모지
- 배경 패턴, 노이즈 텍스처, 블러

**구조**
- 히어로 섹션, 랜딩 페이지 요소
- 마케팅 문구 ("혁신적인", "차세대", "seamless")
- 다크 모드 토글
- 설정 화면, 프로필, 알림 벨

**모션**
- hover 트랜지션
- 스크롤 진입 애니메이션
- 로딩 스피너: 상태 텍스트로 대체한다 (`증명 생성 중`)

## 7. 자가 점검

화면을 만든 뒤 스크린샷을 찍고 아래를 대조한다. 하나라도 걸리면 고친다.

1. 둥근 모서리가 보이는가 → 전부 0으로
2. 그림자나 그라데이션이 보이는가 → 제거
3. 대문자 라벨이 있는가 → 문장 형태로
4. 아이콘이 있는가 → 제거
5. 이 화면이 SaaS 대시보드 템플릿처럼 보이는가 → 밀도를 높이고 여백을 줄인다
6. 움직이는 요소가 도장 말고 또 있는가 → 제거
7. 공개 원장에 채권 내용이 한 글자라도 있는가 → **코드를 삭제한다**
8. 거부 상태에서 금액이 0으로 보이는가 → 안 보이면 추가
9. 스크린샷을 흑백으로 바꿔도 상태 구분이 되는가 → 색만으로 구분하면 텍스트 추가

7번과 8번은 디자인 문제가 아니라 제품 주장의 문제다. 다른 것보다 우선한다.

## 8. 발표에서 화면이 해야 할 일

디자인의 목표는 예쁨이 아니라 이 세 가지를 **말 없이 보여주는 것**이다.

| 주장 | 화면이 증명하는 방법 |
|---|---|
| 장부를 공유하지 않았다 | 금융사 B 패널과 공개 원장 어디에도 채권 내용이 없다 |
| 그런데 중복이 막혔다 | B의 도장이 `이미 사용`으로 찍힌다 |
| 자금이 나가지 않았다 | B의 금액이 `0`으로 남는다 |

발표자가 이 세 곳을 손가락으로 가리킬 수 있어야 한다. 화면 설계는 여기서 역산한다.
