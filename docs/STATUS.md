## 채권 예산

온체인 미사용 3건. A5가 1건, A6가 1건을 **영구 소모**한다. 되돌릴 수 없다.

소모되는 것은 `finance` 트랜잭션이 **확정됐을 때뿐이다.**

| 결과 | 소모 |
|---|---|
| A5 통과 | 1건 |
| A5 판정 불가 (확정 1건) | 1건 |
| **A5 판정 불가 (확정 0건)** | **0건** |
| A6 통과 / 지연 제출만 실패 | 1건 (셋업이 확정되므로) |
| A6 판정 불가 (셋업 미확정) | 0건 |

즉 가장 흔한 실패 — 지갑이 두 트랜잭션을 직렬화해서 생기는 판정 불가 —
는 **채권을 먹지 않는다.**

> **리허설 예산은 따로 만들 수 있다.** `/devtools`의 [배포 시작]으로 자기
> 컨트랙트를 올리면 미사용 채권 3건이 새로 생기고, 그 컨트랙트의 발급
> 권한도 갖게 되어 `/issuer`에서 더 찍을 수 있다. 원본 채권은 한 장도
> 쓰지 않는다. **원본에서 A5·A6을 처음 누르지 마라.**
